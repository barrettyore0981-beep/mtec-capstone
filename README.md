# mtec-capstone
mtec data capstone project
## ABOUT THE DATA 
the data set was found on kaggle and is avalible here: 
https://www.kaggle.com/datasets/asifxzaman/social-media-addiction-vs-productivity-dataset/data

today we spend a lot of time on social media but how does this usage affect us? 

this dataset has infomation for different users and their usage of social media 
including:
* Age
* Daily Screen Time (in hours)
* Social Media Hours
* Study Hours
* Sleep Hours
* Notifications Per Day

as well as overall ratings:

* Focus Score
* Addiction level
* Productivity Score

the goal of this project is to see how how the usage of social media affects us and to explore the possibillity of building a ML model to estimate impact for unseen users
